# 预诊模板配置 - PC 高保真原型规格

## 1. 业务与目标

### 1.1 页面定位

本原型用于展示 `FR 品牌预诊模板配置后台` 的完整工作流，面向主机厂产品经理、运营配置人员、售后规则管理员，支持在 PC 端完成预诊模板的集中维护，并将同一模板适配到 FR 品牌下不同车型。

预诊模板的核心用途：**针对预约单 / 环检单中记录的客户问题，沉淀一套结构化的检查指导**。当门店技师对接到一个具体的故障现象后，可以按模板提供的故障原因清单与工位级排查步骤进行诊断。

该页面不是门店执行端，而是后台配置端，重点解决以下问题：

- 统一管理 FR 品牌预诊模板
- 支持一个模板适配多个车型
- 以"问题分类 → 故障现象 → 可能原因 + 工位级排查步骤 + 专项诊断指导"为核心结构沉淀检查指导
- 支持模板启停与持续维护
- 支持配置结果实时预览，降低沟通与上线成本

### 1.2 视觉基线

- 页面字体、骨架、顶部标签栏、面板边框、按钮密度统一参照 `src/prototypes/pre-diagnosis-rule-config`
- 左侧导航锚点样式参照 `src/prototypes/repair-workorder-m02`（圆角、带间距、悬停效果）
- 使用紧凑的业务后台布局，不增加装饰性大卡片、渐变、浮层式说明区
- 无特别说明时，说明性文字不在原型页面直接展示，只保留业务字段、状态和操作

### 1.3 设计目标

- 设计样式、布局骨架、筛选区、表格、表单和状态标签统一遵循 `src/docs/pc-prototype-design-spec.md` 与默认主题 `src/themes/fuse-design-pc`
- 呈现一个真实可评审的企业后台，而不是概念稿
- 突出 `模板复用 + 问题分类沉淀 + 工位级排查指导` 三个核心价值
- 保持页面操作收敛，状态与动作只保留业务已确认的最小闭环

### 1.4 核心用户任务

- 在模板列表中快速定位某个 FR 预诊模板
- 查看模板已适配的车系、车型和启停状态
- 进入编辑页维护模板基础信息、适配范围
- 维护问题分类树（一级 / 二级），并在二级下挂载具体故障现象
- 为某个故障现象录入"可能的故障原因清单"、"按工位组织的通用技术检查步骤"与"专项深度诊断步骤"
- 在右侧预览查看选中故障现象的预览效果
- 对模板执行启用或停用

## 2. 功能结构

### 2.1 页面结构

```text
预诊模板配置
├── 模板列表页
│   ├── 页面标题与操作区
│   ├── 查询筛选区（模板名称 / 车型 / 状态）
│   ├── 模板表格（含问题分类 / 故障现象数量统计列）
│   └── 行内操作（编辑 / 启用 / 停用）
└── 模板编辑页
    ├── 基础信息（只读）
    ├── 适配车型（卡片可点选预览车型）
    ├── 问题分类与故障现象（左右分栏）
    │   ├── 左：问题分类树（一级分类 → 二级分类 → 故障现象）
    │   └── 右：选中故障现象的详情
    │       ├── 故障现象名称
    │       └── 可能的故障原因清单（系统类别 + 子项，可增删）
    ├── 通用技术检查（按 4 个工位组织步骤卡片）
    │   ├── 接车区
    │   ├── 车内（低压上电，不踩刹车）
    │   ├── 车内（高压上电，踩刹车 ready）
    │   └── 举升机工位
    ├── 诊断指导（步骤标题 + 操作说明 + 关键判断点）
    ├── 实时预览侧栏（按选中故障现象呈现）
    └── 底部固定操作栏（返回 / 保存 / 启用|停用）
```

### 2.2 关键交互

- 列表页点击 `编辑` 进入独立模板编辑页，而不是弹窗编辑
- 列表页状态仅保留 `启用 / 停用`
- 列表页操作仅保留 `编辑 / 启用 / 停用`
- 同一个模板支持关联多个车型，预览区可切换车型查看效果
- 问题分类树支持展开/折叠一级分类；点击故障现象切换详情
- 问题分类树支持批量导入，导入入口位于树工具栏；选择文件后展示解析预览，确认后合并到当前模板
- 故障原因表支持新增、编辑、删除（系统类别 + 子项两列）
- 通用技术检查按工位卡片展示,每个工位可新增步骤；步骤可编辑描述与参考资料；可单独删除步骤（删完最后一步该工位卡片自动留空提示）
- 诊断指导与选中的故障现象强关联，支持新增/编辑/删除专项诊断步骤，并在每个步骤下维护关键判断点
- 右侧预览区固定，按选中故障现象渲染：可能原因列表 + 各工位的步骤序列 + 专项诊断指导

- 故障现象名称（如：车机屏幕黑屏）

#### 故障原因

- 系统类别（如：低压电气系统 / 智能座舱系统）
- 子项 / 说明（如：供电/搭铁、屏幕硬件/主机硬件、软件/系统、网络通讯）

#### 通用技术检查

#### 诊断指导

- 关联对象：具体故障现象（例如 `智能座舱系统 / 屏幕/显示 / 车机屏幕黑屏`）
- 步骤序号（自动维护，第一步 / 第二步 / ……）
- 步骤标题（如：接车区确认症状操作、车内低压上电，基础供电检查）
- 操作说明（支持多行文本）
- 关键判断点（多个，可新增/删除）

#### 示例问题分类

- 智能座舱系统
  - 屏幕/显示
    - 车机屏幕黑屏
    - 车机屏幕闪烁/花屏
  - 人机交互
    - 触控无响应/漂移

#### 示例故障原因（车机屏幕黑屏）

- 低压电气系统 - 供电/搭铁
- 智能座舱系统 - 屏幕硬件/主机硬件
- 智能座舱系统 - 软件/系统
- 低压电气系统 - 网络通讯

#### 示例通用技术检查（车机屏幕黑屏）

- 接车区
  1. 确认客户主诉与黑屏发生场景
  2. 检查 12V 蓄电池电压
- 车内（低压上电，不踩刹车）
  1. 尝试唤醒车机：HOME / 长按 5 秒
  2. 观察仪表与中控同步显示及 CAN 通讯故障码
  3. 确认主机供电保险（F19 / F22）
- 车内（高压上电，踩刹车 ready）
  1. Ready 后再次确认中控显示恢复时长
  2. 读取座舱域控制器（CCM）DTC
- 举升机工位
  1. 拆 B 柱后部线束接插件检查针脚氧化
  2. 代用主机替换法验证

#### 示例诊断指导（车机屏幕黑屏）

- 第一步：接车区确认症状操作
  - 向用户确认：是偶尔黑还是彻底不亮？黑屏时有没有声音（导航/音乐还在响吗）？黑屏前有没有花屏、闪屏、过热、卡顿的前兆？
  - 确认触发条件：暴晒后？颠簸后？洗车后？还是毫无规律？
  - 关键判断点：
    - 屏幕不亮但声音正常/触控有反馈：倾向背光问题、屏幕硬件或背光供电故障
    - 屏幕不亮且完全无声音：倾向主机不开机或系统崩溃，问题在主机端
    - 偶尔黑屏自动恢复：倾向过热保护、软件卡死、接插件虚接
- 第二步：车内低压上电，基础供电检查
  - 车辆低压上电后确认中控屏是否点亮，检查屏幕背光、主机启动声、触控反馈、保险状态与主机供电/搭铁状态，必要时读取座舱域控制器 DTC。

- FR E-Sedan 2025 增程版
- FR X-Pro 2026 四驱高配版

## 4. 布局与结构

### 4.1 整体布局

- 左侧固定导航、顶部工具栏、工作签条、面包屑都遵循项目统一 PC 后台规范
- 内容区采用浅灰背景 + 白色业务卡片 + 细描边 + 弱阴影
- 页面不做营销化视觉，不使用大面积渐变和过强装饰
- 信息密度偏高，但通过分区、卡片和固定预览控制阅读压力

### 4.2 列表页布局

- 顶部为页面标题与 `新建模板` 主按钮
- 下方为紧凑型筛选区，优先字段为 `模板名称 / 车型关键字` 与 `状态`
- 表格位于主要视觉中心，支持横向滚动以适应车型字段
- 操作列固定靠右，文本按钮样式简洁

### 4.3 编辑页布局

- 采用 `左侧导航 + 中部配置 + 右侧预览` 三栏结构
- 左侧导航宽度收敛，强调定位与跳转
- 中部配置区为主要工作区，支持多模块纵向滚动
- "问题分类与故障现象" 模块在中部配置区内部再做一次左右分栏：左为问题分类树（280px），右为故障现象详情
- "通用技术检查" 模块按 4 个工位以 2×2 网格卡片展示步骤
- "诊断指导" 模块位于通用技术检查之后，作为最后维护的独立面板展示步骤标题、操作说明和关键判断点
- 右侧预览区固定展示，便于边改边看
- 底部固定操作栏提供：
  - 保存
  - 启用模板
  - 停用模板

### 4.4 预览区布局

- 顶部为车型切换器
- 中部为执行端模板结构模拟
- 差异项使用标签、浅色背景或描边高亮
- 不展示冗长说明文案，优先展示结构、字段和状态

### 4.5 响应式适配

- 桌面端（≥1440px）：完整三栏布局
- 中等桌面（1200-1439px）：右侧预览区宽度收窄
- 窄屏场景（<1200px）：右侧预览可折叠为抽屉

## 6. 交互规则

1. 一个模板可适配多个车型
2. 模板内容维护顺序为：问题分类与故障现象 → 通用技术检查 → 诊断指导
3. 一个二级分类下允许挂载多个故障现象；一个故障现象允许有多个故障原因；一个故障现象的通用技术检查按 4 个工位组织，每个工位下若干步骤；诊断指导作为最后一步与该故障现象绑定
4. 状态仅允许为：
   - 启用
   - 停用
5. 操作列仅允许为：
   - 编辑
   - 启用
   - 停用
6. 当模板处于启用状态时，列表中展示 `停用`；停用状态时列表中展示 `启用`
7. 编辑页保存后不改变状态，启用/停用为独立动作
8. 选中故障现象后，问题分类与故障现象、通用技术检查、诊断指导三个维护模块与右侧预览区联动刷新
9. 故障原因表与工位步骤均支持新增、编辑、删除；删除工位最后一步时，该工位卡片回到空提示状态
10. 诊断指导与故障现象强关联，切换问题分类树中的故障现象时，专项指导内容同步切换
11. 诊断指导支持新增、编辑、删除步骤；每个步骤支持维护多条关键判断点
12. 导入支持 XLSX、JSON、CSV、TSV、TXT 文件，表格字段为：一级分类、二级分类、故障现象、系统类别、故障原因、工位、步骤描述、参考资料
13. 导入数据必须至少包含一级分类、二级分类、故障现象；确认导入后按名称合并到当前模板，重复原因和重复步骤不重复追加
14. 导入组件参考后台导入文件样式：顶部展示 `下载模板`，中间为点击/拖拽上传区，下方包含导入时间筛选和数据列表
15. 点击 `下载模板` 应下载 Excel 模板，模板内置标准表头与示例行；模板回传上传后可被解析
16. 导入成功后自动展开受影响的一级分类，并选中首个导入或合并的故障现象
17. 禁止使用复杂发布流、审核流、草稿流

## 7. 验收要点

- 具备 `列表 -> 编辑 -> 预览` 的完整闭环
- 能明确看出 `一个模板适配多个车型`
- 编辑页能清楚呈现"一级分类 → 二级分类 → 故障现象"的层级关系

- 故障原因表至少展示 1 行编辑能力（增删改）
- 通用技术检查至少能在 4 个工位卡片中：新增步骤、编辑步骤描述与参考、删除步骤
- `车机屏幕黑屏` 默认展示与 `智能座舱系统 / 屏幕/显示` 关联的诊断指导，包含接车区确认症状操作与车内低压上电基础供电检查
- 诊断指导可新增自定义步骤、编辑操作说明、新增/删除关键判断点，并在右侧预览同步展示
- 点击问题分类树中的 `导入` 能弹出导入弹框；弹框视觉包含 `下载模板`、拖拽上传区、导入时间筛选和数据列表
- 点击 `下载模板` 可下载 Excel 导入模板；上传该模板或合法 XLSX/JSON/CSV/TSV/TXT 文件后展示分类、现象、原因、工位、步骤数量预览
- 导入记录列表应展示记录ID、导入时间、操作人、文件名、状态、总数和下载操作
- 确认导入后页面树、详情和右侧预览同步刷新
- 导入空文件、字段缺失文件或格式错误 JSON 时，页面应展示明确错误提示，且不会改动当前模板
- 列表状态只有 `启用 / 停用`
- 操作列只有 `编辑 / 启用 / 停用`
- 页面整体风格符合项目 PC 后台规范
- 原型具备高保真视觉质量，适合评审展示
