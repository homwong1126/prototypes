# 主机厂权益中心管理后台 - 高保真原型规格

## 📋 业务与功能

### 1.1 核心目标
主机厂运营人员在后台统一配置、管理和发放各类车主权益，支持权益规则设置、发放策略配置、数据统计查看。

补充约束：页面品牌 Logo 等本地图片资源统一采用模块静态导入，不使用 `'/src/...'` 形式的运行时路径，保证开发预览、构建产物与导出文件加载一致。

### 1.2 功能清单（Tab 页划分）
- **Tab 权益总览**：各类权益数量统计 + 近期操作记录
- **Tab 商城权益**：积分规则配置 + 优惠券模板管理 + 批量发放
- **Tab 保养套餐**：套餐内容配置 + 适用车型 + 价格设置
- **Tab 道路救援**：救援次数规则 + 服务商配置
- **Tab 延保服务**：延保规则 + 覆盖范围 + 价格配置
- **Tab 终身质保**：质保条件 + 覆盖零件 + 激活规则

### 1.3 权益类型
| 类型 | 说明 |
|------|------|
| 商城权益 | 积分规则、优惠券模板、发放策略 |
| 保养套餐 | 套餐内容、适用车型、次数、有效期 |
| 道路救援 | 年度救援次数、服务范围、服务商 |
| 延保服务 | 延保年限、覆盖范围、购买条件 |
| 终身质保 | 质保零件范围、激活条件、转让规则 |
