4. 用户旅程

用户旅程流程说明如下：

  1. 门店销售进入订单管理-订单录入，填写订单基本信息与订单信息并保存。
  2. 保存订单时系统计算预估综合毛利；若订单触发限价审批，系统自动生成限价申请单。
  3. 用户在订单详情查看「新车开票」信息块，只能查看不可编辑。
  4. 点击「编辑」：
    • 若该订单存在未完成审批的限价申请单（待审核/审批中），弹框提醒："订单已触发限价审批，通过限价管理-限价申请跟踪审批进度。"，本次不允许进入编辑。
    • 若该订单未触发限价审批，直接进入新车开票信息编辑态。
  5. 编辑态下修改开票字段并上传发票附件，可「退出编辑」放弃修改或「保存」提交。
  6. 保存成功后退出编辑态，卡片以只读形式展示最新数据。

5. 数据流图

数据流流程说明如下：

  1. 订单录入保存后，订单数据写入订单主档。
  2. 订单毛利相关字段由系统按订单金额、单车成交价与税率计算。
  3. 预估综合毛利写入订单，并参与限价管理模块审批触发判定。
  4. 限价审批状态（未触发/审批中/已通过/已驳回）回传订单，约束新车开票编辑权限。
  5. 新车开票保存后，开票信息与发票附件写入订单开票数据。

6. 状态机

新车开票信息关注的状态节点如下：

  • 只读态：默认展示开票字段值，操作列仅显示「编辑」按钮。
  • 编辑拦截：订单存在未完成审批的限价申请单时，点击编辑弹出审批提醒，不进入编辑态。
  • 编辑态：订单未触发限价审批时点击编辑进入，字段可编辑，提供「退出编辑」「保存」按钮。
  • 保存成功：退出编辑态回到只读态，展示最新数据。
  • 退出编辑：放弃本次修改，数据回滚为编辑前值。

注：原型提供"演示：有限价审批未完成"开关，用于展示两种分支：命中审批弹出提醒阻断编辑，未命中直接进入编辑态。

7. 功能原型

原型来源：订单管理录入（src/prototypes/order-manage-entry）。

所属模块：订单管理

核心业务规则：

  • 订单录入字段按民事必填规则校验，未填写完整时提示"请完善必填项"。
  • 预估综合毛利仅支持整数，可为负整数，不可输入小数点。
  • 新车开票信息块默认只读；点击编辑时校验限价审批状态。
  • 存在未完成审批的限价申请单时，弹框提醒"订单已触发限价审批，通过限价管理-限价申请跟踪审批进度。"并阻断编辑。
  • 未触发限价审批时直接进入编辑态，可退出编辑、可保存。
  • 发票附件为必填项，支持上传与删除，限制指定文件格式。

11. 业务规则总结

  1. 订单录入必填：客户信息、车辆信息、订单信息、单车成交价、预估综合毛利、试乘试驾等字段必填，未填完整提示"请完善必填项"。
  2. 预估综合毛利校验：仅支持整数，可为负整数，不可输入小数点。
  3. 新车开票默认只读：订单录入页展示新车开票信息块，默认只读，仅提供「编辑」入口。
  4. 限价审批约束编辑：编辑前校验限价申请状态；存在未完成审批的限价申请单时弹框提醒"订单已触发限价审批，通过限价管理-限价申请跟踪审批进度。"并阻断编辑。
  5. 直接编辑：订单未触发限价审批时，点击编辑直接进入编辑态，可退出编辑、可保存。
  6. 开票必填：开票日期、新车收入、税率、是否地补、发票购买方、开票金额、现价金额及发票附件必填。
  7. 附件格式：支持 .rar,.zip,.pdf,.jpg,.png,.jpeg,.ppt，发票附件至少上传一张。

12. 权限控制

  • 门店销售：可录入订单、维护新车开票信息（受限价审批状态约束）。
  • 财务：可查看开票信息，编辑权限待确认。
