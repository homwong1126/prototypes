# 政策管理编辑本地项目说明

本目录基于 `policy-management-edit` 高保真原型补齐了可本地运行的业务骨架，适合继续做前后端联调前的本地开发。

## 已补齐能力

- 政策基本信息编辑（政策编号、政策名称、采购类型）
- 政策车型信息表格展示（11条示例车型数据）
- 车型信息新增、删除功能
- 核销金额和终止日期编辑
- 表格数据本地状态管理

## 本地启动

在仓库根目录执行：

```bash
npm run dev
```

默认访问路径：

```text
/prototypes/policy-management-edit
```

## 构建与预览

```bash
npm run build
npm run preview
```

## 功能说明

### 政策基本信息
- 政策编号：只读字段，系统自动生成
- 政策名称：可编辑
- 采购类型：可编辑

### 政策车型信息
- 表格展示11条示例车型数据
- 支持新增车型行
- 支持删除车型行
- 核销金额和终止日期可编辑
- 支持导出功能（UI已实现）

### 操作按钮
- 返回：返回上一页
- 保存：保存当前编辑内容（控制台输出）

## 技术栈

- React 18
