4. 用户旅程

  1. 门店人员进入市场费用管理，默认落在门店待办事项，查看需本门店处理的计划单。
  2. 门店人员点击新增，基础信息只读带出，年/月默认当前月，选择项目分类枚举并填写费用信息后提交，流转至总部审核。
  3. 总部审核人员切换至总部待办事项，仅见当前操作含总部的单据，逐条总部审核；勾选≥2 条时出现批量审核按钮，一次审核多单。
  4. 总部审核通过后，单据回到门店待办，操作列显示门店核销（首次登记入口）。
  5. 门店执行门店核销：是否执行=是时出现是否核销；是否核销=是时才出现回款与核销明细；登记首笔回款并上传附件。
  6. 财务审核回款后，若待回款未清零（分批场景），单据状态默认为挂起，门店待办操作列变为回款登记，继续分批登记直至待回款为 0。
  7. 待回款清零后单据状态变更为已完成，操作列变为查看。
  8. 总部审核退回的单据，门店点编辑可改项目信息及附件；财务审核退回的单据，门店点编辑可改核销登记相关数据。

5. 数据流图

  1. 新增页写入市场计划单基础与项目信息，提交后生成待总部审核单据。
  2. 总部审核（含批量）回写当前操作（通过/不通过）与下一步操作（门店核销/门店修改提交）。
  3. 门店核销写入是否执行/是否核销，并新增首笔回款记录与附件。
  4. 财务审核回写回款状态（确认到账/已到账）与核销状态（待核销/已核销）。
  5. 系统按厂家承担 - 已登记回款实时计算待回款/可登记，驱动挂起/已完成与回款登记按钮。
  6. 退回按层级路由：总部退回开放项目信息编辑，财务退回开放核销数据编辑。

6. 状态机

  • 审批中：新增提交后，总部待办可见，操作为总部审核。
  • 待核销：总部审核通过，门店待办操作为门店核销。
  • 挂起：财务审核通过但待回款未清零（分批回款中），门店待办操作为回款登记。
  • 退回：总部/财务审核不通过，门店待办操作为编辑（总部退回改项目、财务退回改核销）。
  • 已完成：待回款清零，操作为查看。
  • 已结束：是否执行=否或是否核销=否，无需回款核销，操作为查看。
  • 待总部审核：新增提交后，总部待办可见，操作为总部审核。
  • 待核销：总部审核通过，门店待办操作为门店核销。
  • 挂起：财务审核通过但待回款未清零（分批回款中），门店待办操作为回款登记。
  • 退回：总部/财务审核不通过，门店待办操作为编辑（总部退回改项目、财务退回改核销）。
  • 已完成：待回款清零，操作为查看。

流转关系：

  • 新增 → 待总部审核；总部通过 → 待核销（门店核销）；门店核销登记 → 财务审核。
  • 财务通过且待回款 > 0 → 挂起（回款登记）；财务通过且待回款 = 0 → 已完成。
  • 总部不通过 → 退回（可编辑项目信息）；财务不通过 → 退回（可编辑核销数据）；重新提交后回到对应审核节点。

7. 功能原型

原型来源：市场费用管理（src/prototypes/market-plan-manage，含 index.tsx 与 style.css）。

所属模块：市场费用管理 / 市场计划管理

核心业务规则：

  • 三待办分流：门店待办（下一步操作含门店/核销）、财务待办（财务相关）、总部待办（当前操作含总部）。
  • 总部待办仅显示总部审核按钮；勾选≥2 条才出现批量审核；审核默认通过，退回时必填退回意见。
  • 核销联动：是否执行=是才出现是否核销；是否核销=是才出现回款与核销明细。
  • 回款附件：明细栏内每笔上传、至少 1 张、支持多张，缩略图悬停显示预览/下载/删除。
  • 明细操作：待财务确认行支持确认到账＋删除整行；待核销行支持核销本次＋删除整行。
  • 待回款高亮：待回款/可登记金额以赭橙色（#c05a00）高亮。
  • 编辑分权：总部退回改项目信息及附件，财务退回改核销登记数据；详情为 readonly。

11. 业务规则总结

11.1 核心业务规则

  1. 待办分流：门店/财务/总部三待办按当前操作与下一步操作归属过滤；总部待办仅总部审核按钮。
  2. 批量审核：仅总部待办且勾选≥2 条出现；默认通过，退回必填退回意见。
  3. 核销联动：是否执行=是才出是否核销；是否核销=是才出回款与核销明细。
  4. 分批回款：首次为门店核销，后续为回款登记，直至待回款为 0；待回款未清零默认挂起，清零为已完成。
  5. 附件规则：每笔回款至少 1 张、可多张；在明细栏上传；缩略图悬停预览/下载/删除。
  6. 退回分权：总部退回改项目信息及附件，财务退回改核销登记数据。
  7. 编辑入口：仅退回/不通过态出现编辑；其余为核销/回款/查看。

11.2 数据校验规则

  • 回款金额 > 0 且 ≤ 待回款/可登记余额。
  • 退回时退回意见必填；通过时隐藏。
  • 保存时每笔回款附件非空（至少 1 张）。
  • 新增时基础信息只读，项目信息必填；分类限枚举 7 项。

11.3 权限控制

  • 门店人员：新增、门店核销、回款登记、退回编辑、附件管理。
  • 财务人员：财务审核、到账确认、核销确认。
  • 总部人员：总部审核、批量审核。
