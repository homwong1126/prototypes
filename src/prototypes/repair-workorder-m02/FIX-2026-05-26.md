# 经营权限确认后弹框显示问题修复

## 问题描述
确认经营权限后打开的弹框只显示"车辆权益"内容，缺少"关联预约单"、"服务活动/品质改善"、"维修建议"等其他Tab的内容。

## 问题原因
在之前的优化中，为了实现"独立按钮模式"（每个按钮只显示对应内容），在代码中添加了对 `vehicleInsightTabs` 的过滤：

```typescript
const vehicleInsightTabs = [
  // ... tab definitions
].filter(tab => tab.key === vehicleInsightsTab)  // ❌ 固定过滤，导致只显示当前Tab
```

这个过滤逻辑是固定的，导致即使在"完整模式"下也只能看到当前选中的Tab。

## 解决方案
根据弹框模式（`vehicleInsightsModalMode`）动态决定是否过滤Tab列表：

```typescript
const allVehicleInsightTabs = [
  { key: 'appointment', label: '关联预约单', count: pendingAppointmentCount },
  { key: 'rights', label: '车辆权益', count: 0 },
  { key: 'campaign', label: '服务活动 / 品质改善', count: pendingCampaignQualityCount },
  { key: 'suggestion', label: '维修建议', count: pendingRepairSuggestions.length },
]

// ✅ 根据模式动态过滤
const vehicleInsightTabs = vehicleInsightsModalMode === 'full' 
  ? allVehicleInsightTabs  // 完整模式：显示所有Tab
  : allVehicleInsightTabs.filter(tab => tab.key === vehicleInsightsTab)  // 独立模式：只显示当前Tab
```

## 修改内容

### 1. 添加弹框模式状态

```typescript
const [vehicleInsightsModalMode, setVehicleInsightsModalMode] = useState<'full' | 'single'>('full')
```

```typescript
const openVehicleInsightsModal = (
  tab: 'appointment' | 'rights' | 'campaign' | 'suggestion' = 'appointment',
  mode: 'full' | 'single' = 'single'  // 新增mode参数
) => {
  // ...
  setVehicleInsightsModalMode(mode)
  // ...
}
```

### 3. 经营权限确认使用完整模式
```typescript
openVehicleInsightsModal('rights', 'full')  // 使用full模式
```

### 4. Tab导航栏根据模式显示/隐藏
```typescript
<div className="tab-nav" 
     style={{ display: vehicleInsightsModalMode === 'full' ? 'flex' : 'none' }}>
  {/* ... */}
</div>
```

### 5. Tab数据根据模式过滤
```typescript
const vehicleInsightTabs = vehicleInsightsModalMode === 'full' 
  ? allVehicleInsightTabs 
  : allVehicleInsightTabs.filter(tab => tab.key === vehicleInsightsTab)
```
