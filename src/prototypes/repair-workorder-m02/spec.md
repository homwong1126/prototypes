# M02 维修工单管理 - 高保真原型规格

## 📋 业务与功能

### 1.1 核心目标

面向 4S 店服务顾问、维修技师、班组长的维修工单全生命周期管理页面。覆盖工单列表、工单创建（含环检/预诊）、上门服务、委托书详情、维修历史查询、电池维修登记五大核心场景，通过左侧导航与业务入口切换展示。

补充约束：页面品牌 Logo 等本地图片资源统一采用模块静态导入，不使用 `'/src/...'` 形式的运行时路径，保证开发预览、构建产物与导出文件加载一致。

### 1.2 功能清单（Tab 页划分）

- **Tab 1 - 工单列表**：工单状态标签栏 + 4列紧凑型列表筛选 + 快捷操作
- **Tab 2 - 创建工单**：车辆查询 + 车主/车辆标签 + 车主信息 + 车辆信息 + 工单信息 + 车辆售后信息 + 故障信息 + 维修项目（含套餐/故障部位，派工后显示技师/工位）+ 备件（含套餐/活动、是否供应商直供，领料后显示发料人/领料人）+ 其他费用（含关联单据）+ 费用汇总
- **Tab 3 - 上门服务**：在维修工单体系内按 `上门服务` 范围展示委托书列表，支持派车派工、领料、出发、到达、环检及后续施工流转
- **Tab 4 - 委托书详情**：委托书详情页 + 状态节点流转 + 环检记录 + 施工记录 + 完工自检
- **Tab 5 - 维修历史**：统计卡片 + 历史列表 + 详情弹窗
- **Tab 6 - 电池维修登记**：电池基础信息 + 检测数据 + 维修/更换信息 + 安全检查清单
- **Tab 7 - 工单模板**：模板分类 + 模板列表 + 模板新增编辑
- **Tab 8 - 工时单价设置**：车型维度可选的工时标准列表 + 新增工时单价弹窗 + Excel 导入预览

补充视觉基准：页面设计风格、元素密度、字体层级、工具栏与表格样式统一遵循 `src/docs/pc-prototype-design-spec.md`，按项目默认的 PC 端高保真后台规范输出。

### 1.3 交互要点

- 工单列表：内容区顶部仅保留 `维修业务 / 工单列表` 面包屑，不再展示横向业务 Tab 标签栏；高级查询区默认按 5 列栅格排布高频条件，首排固定为 `品牌 / VIN / 车牌号 / 客户姓名 / 委托书编号`，第二排展示 `预约单号 / 服务顾问 / 送修人手机号`，并将 `查询 / 重置 / 展开` 操作直接放在该排尾部剩余两格内，避免默认态留白；查询项标签统一改为上标签、下控件的上下结构；展开后展示日期范围与单据状态等低频条件，其中 `开单日期 / 完工时间 / 结算日期 / 确认开工日期 / 单据状态` 保持同一行展示，且“收起”入口移动到全部查询条件的最下方；查询项之间不使用内部横竖分隔线，保持留白式分组；日期范围组件采用“上方开始/结束输入 + 下方双月日历面板”的样式；“单据状态”位于“确认开工日期”后方，筛选项包含新建、待确认、待派工、待完工、待质检、待交车、已交车；创建工单与导出位于数据列表操作区；列表中的客户姓名与送修人默认仅展示首字，其余字符脱敏，送修人手机号去除分隔符并隐藏中间 4 位，三项敏感信息均支持点击眼睛按钮切换为明文展示；待派工单据在操作列显示“派工”，点击后需按维修项目分配到“班组 - 主责任技师”；待交车单据在操作列显示“交车”按钮，点击后进入交车管理页
- 三包预警：工单命中三包预警时，`1 / 2 / 3 / 4 / 5` 级均弹出提醒弹窗；`1 / 2 / 3` 级确认后允许继续查看、派工、交车等处理；`4 / 5` 级在弹窗出现前即直接锁定工单，派工、交车、返修等动作禁用，弹窗内需提供“查看委托书详情 / 查看预警报告”入口，供服务顾问与三包专员继续复核
- 数据列表：首列字段名统一使用“委托书编号”；点击“委托书编号”或“查看” → 跳转至委托书详情页；委托书编号列仅展示单号本身，不在单号下叠加“新能源”“品质改善”等标签；新增独立字段 `能源类型`，展示 `燃油 / 混动 / 纯电 / 增程` 等枚举；每个字段表头均提供复制、排序、查询入口，查询浮层支持输入内容批量匹配、全选、单项勾选、筛选和重置；操作列每行仅保留一个“查看”入口，其他状态动作通过按钮或更多操作呈现；“更多”下拉以页面浮层方式展示，不被表格滚动容器或卡片边界遮挡；点击“数据列表”标题右侧的齿轮 icon 入口 → 打开“字段配置”弹层，可进行字段显示/隐藏、拖拽排序、冻结字段设置；操作列固定在列表最右侧，横向滚动时始终可见
- 创建工单：输入车牌 → 自动回填车辆信息；车辆信息区补充“关联预约单”“任务委托书履历”“车辆权益”“服务活动”“维修建议”五个动作入口，并新增“相关标签”摘要，默认仅显示客户画像/权益命中数量，不直接暴露车辆用途、车辆性质、VIP、保养套餐、延保产品、代金券、充值卡等敏感标签文本；服务顾问主动点击后才展开标签明细；点击“关联预约单” → 弹出预约单匹配弹窗，仅保留 1 条匹配预约单数据，展示预约单号、预约来源、车牌号、VIN、客户姓名、手机号、预约时间、预约类型、状态，选择预约单后回填车牌、VIN、车主姓名、手机号、车型和服务方式，并在创建工单数据中记录预约单号；服务方式字段位于“工单信息”区、紧跟“工单号”之后；若关联预约单服务方式为 `上门服务`，停留在当前创建流程，并在工单信息区展示上门地址字段；点击“任务委托书履历” → 在当前创建工单页弹出当前车辆维修历史弹框，展示历史摘要与历史记录列表，并支持按单条记录“一键带入当前工单”；创建工单时须判断保养套餐、延保、代金券与充值卡可用情况；当通过车牌或 VIN 命中车辆并完成回填后，自动弹出整合弹窗，将车辆权益、服务活动、维修建议集中展示；其中权益标签默认采用摘要态显示，需手动展开后查看具体标签内容；默认全部勾选，服务顾问可取消勾选后确认；服务活动确认后加入本次工单，维修建议确认后直接加入当前工单明细并按增项标识展示；维修建议名称使用项目名称口径展示；点击“按 VIN 查询车辆” → 打开车辆查询弹窗，支持本店车辆查询、车辆精确查询、它牌车查询；VIN 输入不足 17 位时即时提示校验错误；服务方式保留 `救援到店 / 上门服务 / 救援 / 取车到店 / 技术万里行` 五项枚举，默认救援到店；当选择 `上门服务` 时不跳转外部移动服务页面，创建成功后进入上门委托书列表统一流转；添加维修项目 → 自动计算工时费；创建页维修项目与备件名称不展示额外“项目/备件”标签；`套餐/活动` 字段全程只读展示，无值统一回填 `—`；已派工项目与已领料备件在操作列仅显示 `—`；备件折扣支持逐行编辑并实时回算费用，已领料行保持只读；发料人、领料人仅展示姓名；“添加套餐包”弹窗中的 `创建时间` 查询复用工单列表 `完工时间` 同款日期范围组件与堆叠式标签样式；创建工单页不再提供独立“增项处理”Tab；含动力电池项目 → 弹出电池登记提示
- 车辆选择：选中“实销完成”状态车辆后，先弹出“经营权限提示”弹框，展示维修权限 / 保修权限 / 电池维修权限，用户确认后再回填车辆信息；该弹框需保持业务弹窗样式，仅保留标题、权限状态与确认动作
- 委托书详情：整体沿用“创建工单”页面结构，以只读模式展示；顶部保留状态节点 `待确认-待派工-待完工-待质检-待交车-已交车`，已完成节点为绿色，当前节点为黄色，未到达节点为灰色圆圈；详情主体按「车主标签 & 车辆标签 → 车主信息 → 车辆信息 → 工单信息 → 车辆售后信息 → 故障信息 → 维修项目信息 → 备件信息 → 其他费用 → 费用汇总」顺序展示；维修项目/备件表格在卡片内横向滚动，项目名称与备件名称列自适应换行；维修项目表含项目代码、套餐/活动、故障部位、折扣等列，派工后展示技师/工位；备件表含套餐/活动、是否供应商直供、收费类型，领料后展示发料人/领料人，二者仅显示姓名；费用汇总展示工时费、备件费、其他费用、折扣汇总、预估总额，收费拆分（保险/索赔/内结/自费）置于次要行；详情页顶部操作区上方仅保留面包屑，不再额外展示页标题；详情页顶部操作保留“打印委托书”“查看结算信息”，不提供“打印工单”；当从待交车列表点击“交车”进入时，页面切换为交车管理视图，顶部展示维修委托书基本信息、`质检已通过` 状态和 `客户自费结算已结清` 信息，点击“确认交车”后委托书状态变更为 `已交车`
- 草稿与客户确认：点击“保存草稿”后页面在费用汇总下方展开“客户确认 & 附件上传”卡片，用于补充附件（jpg/png/pdf）并完成客户确认；客户未确认时底部“推送车主”按钮禁用；客户确认后点击“推送车主”，委托书进入待派工；当服务方式为 `上门服务` 且已确认备件存在缺料时，推送前先 toast 提示“备件存在缺料，是否仍旧出车？”，并弹出缺料出车确认弹窗，确认后仍可推送上门工单
- 派工入口与派工视图：委托书详情顶部在 `待派工` 状态下展示主色“派工”按钮（工单锁定时禁用），点击后切换到派工管理视图；派工管理视图采用全宽“可用技师时间”面板：顶部含日期选择器、`可用 / 预约 / 工单 / 本次派工` 图例；表格首两列为技师与能力标签，时间轴覆盖 08:00-19:00；空白时段点击即弹出“选择技师时间”弹框（维修项目多选 + 起止时间），已派工时段以蓝色卡片标识、点击可重新编辑或删除；底部展示“预估服务时间”起止区间，点击“确认派工”后委托书状态推进到 `待完工` 并写入确认开工时间
- 上门服务流转：Tab3 上门服务复用工单列表能力，按 `serviceType=onsite` 过滤展示；状态流为 `待派工 / 待领料 / 待出发 / 已出发 / 待环检 / 待开工 / 待完工 / 待质检 / 待结算 / 待回程 / 待退料 / 完成`；待派工显示“派车派工”，确认派工时必须选择服务车辆并写入服务车编号、车牌与技师；待领料显示领料确认弹窗，基于工单已确认备件展示需求数量、可用库存与缺料状态，确认后进入待出发；待出发点击确认出发进入已出发；已出发点击确认到达进入待环检；待环检点击完成环检后进入待开工，并在详情时间轴记录对应节点时间
- 维修历史：点击"查看详情" → 弹窗展示完整工单；切换本门店/全网络 → 列表刷新；全网络模式下隐藏价格敏感信息，仅保留脱敏后的客户与送修人信息展示
- 电池登记：安全检查清单未全勾选 → 拦截提交并提示

## 🔄 批量操作功能

### 项目/备件批量操作

**功能入口**：
- 项目/备件信息表格首列增加复选框列
- 表头复选框支持全选/取消全选
- 每行复选框支持单独勾选

**批量操作栏**：
- 选中至少一项后，表格上方显示批量操作栏
- 显示已选数量：`已选 N 项`
- 提供四个操作按钮：
  - 批量设置折扣（仅对维修项目生效，备件折扣按行单独调整）
  - 批量设置维修类型
  - 批量设置收费类型
  - 取消选择

**批量设置折扣**：
- 弹窗输入折扣比例（0-100%）
- 仅对选中的维修项目生效
- 自动重新计算费用
- 完成后显示成功提示并取消选择

**批量设置维修类型**：
- 弹窗选择维修类型（维修/保养/品质改善/服务活动/事故/精品加装(装潢)/GoodWill）
- 对选中的所有项目和备件生效
- 完成后显示成功提示并取消选择

**批量设置收费类型**：
- 弹窗选择收费类型（客户自费/索赔/保险/内结）
- 对选中的所有项目和备件生效
- 自动应用默认分担配置
- 完成后显示成功提示并取消选择

**“添加项目/备件”弹框内批量设置**：
- 在选择器弹框中勾选至少一项后，于已选提示行下方展开“批量设置（应用于本次添加）”工具栏
- 维修项目 Tab 提供三项默认值：折扣(%)（0-100，仅对非自定义工时项生效）、维修类型、收费类型；备件 Tab 提供两项：维修类型、收费类型；备件折扣在回填后的明细表中逐行维护，已领料行不允许修改
- 默认值为“不修改”，仅对本次确认回填的项目/备件生效，已存在的工单行不受影响
- 维修类型为 `GoodWill` 时，收费类型自动锁为 `索赔`；自定义工时（编号 9999）默认折扣保持 100%、收费类型不可设为 `索赔`
- 工具栏提供“重置”按钮一键清空当前批量默认值；关闭弹框或确认后状态自动重置

**批量导入功能**：
- 点击"批量导入"按钮打开导入弹窗
- 支持从 Excel 复制粘贴数据
- 数据格式：`名称[Tab]编码[Tab]单价[Tab]工时数或数量`
- 自动识别规则：
  - 工时数 < 100：识别为维修项目
  - 工时数 ≥ 100 或无工时数：识别为备件
- 导入后自动添加到对应列表
- 显示导入成功数量提示

**示例数据格式**：
```
更换机油滤清器	A11-001	45	0.5
机油滤清器	P-FLT-001	45	1
更换空调滤芯	A11-002	88	0.3
空调滤芯	P-ACF-205	88	2
```
