# 待完工工单编辑功能 - 快速指南

## 🚀 快速开始

### 1. 启动开发服务器

```bash
npm run dev
```

访问：http://localhost:51720/

### 2. 查看示例工单

1. 打开浏览器访问开发服务器地址
2. 进入"维修工单管理"页面
3. 在工单列表中找到 **WO-2026-0327-011**
4. 这是专门用于演示编辑功能的示例工单

### 3. 测试编辑功能

#### 步骤 1：查看操作列按钮
- 找到 WO-2026-0327-011 工单
- 操作列应显示：**查看 | 编辑 | 完工 | 更多 ▼**
- 点击"更多"查看下拉菜单

#### 步骤 2：进入编辑模式
- 点击"编辑"按钮
- 页面跳转到委托书详情页
- 项目信息和配件信息卡片显示"编辑中"标签

#### 步骤 3：测试已派工项目（不可编辑）
- 查看"更换机油"项目
- 尝试点击任何字段，应该无法编辑
- 状态列显示"🔒 已派工"
- 操作列不显示删除按钮

#### 步骤 4：测试未派工项目（可编辑）
- 查看"更换空调滤芯"项目
- 点击工时单价，修改数值
- 观察费用是否实时更新
- 操作列显示红色"删除"按钮

#### 步骤 5：测试增项（可编辑 + 特殊标识）
- 查看"更换变速箱油"项目
- 行底色应为浅黄色
- 项目名称旁显示橙色"增项"标签
- 可以编辑所有字段

#### 步骤 6：测试新增项目
- 点击"添加项目（增项）"按钮
- 选择一个维修项目
- 新增项目应自动标记为增项
- 行底色为浅黄色，带"增项"标签

#### 步骤 7：测试保存
- 修改一些可编辑字段
- 点击"保存修改"按钮
- 观察是否成功保存并退出编辑模式

#### 步骤 8：测试取消
- 再次点击"编辑"进入编辑模式
- 修改一些字段
- 点击"取消编辑"按钮
- 观察改动是否被丢弃

## 🐛 常见问题

### Q1: 找不到 WO-2026-0327-011 工单？
**A**: 确保开发服务器正常运行，刷新页面后在工单列表中查找。

### Q2: 点击编辑按钮没反应？
**A**: 检查工单状态是否为"待完工"，以及是否被三包预警锁定。

### Q3: 修改后费用没有实时更新？
**A**: 检查浏览器控制台是否有错误，确保代码正常运行。

### Q4: 保存后数据没有变化？
**A**: 数据保存在 localStorage 中，刷新页面后应该能看到变化。
