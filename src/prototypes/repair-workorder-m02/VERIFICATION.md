## 测试用例

### 用例 1：完整工单流程
1. 创建新工单 → 待派工
2. 点击"派工" → 待完工
3. 点击"完工" → 待质检 ✨
4. 点击"质检" → 待交车 ✨
5. 点击"结算" → 记录结算时间 ✨
6. 点击"交车" → 已交车
7. 查看时间轴，所有节点时间完整显示 ✨

### 用例 2：质检失败返修
1. 待质检工单点击"质检"
2. 模拟质检失败（需要在代码中添加失败选项）
3. 工单状态变为"待完工"
4. 时间轴保留之前的完工时间

### 用例 3：三包预警锁定
1. 查看带有4级或5级预警的工单
2. 所有操作按钮被禁用
3. 无法进行派工、完工、质检、结算、交车操作

**预期结果：**

- `维修建议` 按钮文案显示 `维修建议（3）`

### ✅ 7. 整合弹窗 Tab 切换
**验收步骤：**
1. 点击任意入口按钮，弹窗打开
2. 弹窗 header 固定为 `车辆权益 / 服务活动 / 维修建议`
3. Tab 标签顺序：`关联预约单(3) | 车辆权益 | 服务活动 / 品质改善(4) | 维修建议(3)`
4. 数量为 0 的 Tab 不显示徽标
5. 不同入口按钮打开后默认激活对应 Tab

### ✅ 8. 关联预约单 Tab
- 顶部展示当前车牌、车主、匹配提示
- 表格列：选择 / 预约单号 / 命中方式 / 预约来源 / 车牌号 / VIN / 客户姓名 / 手机号 / 预约时间 / 服务方式 / 状态
- 单选选中预约单后，底部 `关联选中预约单` 按钮回填车辆 & 服务方式，关闭弹窗，主信息带显示已关联预约单号

### ✅ 9. 服务活动 / 品质改善 Tab
- 上方为「服务活动」表格，下方为「品质改善（召回 / 技术升级）」表格
- 每个表头 label 旁有全选 checkbox 和待处理徽标
- 品质改善表格的「分类」列：召回 = 红色 `tag-fail`，技术升级 = 蓝色 `tag-pending`
- 勾选后点击底部 `确认`：服务活动写入项目明细 `type='服务活动'`，品质改善写入 `type='品质改善'`，并标记为「已加入工单」

### ✅ 10. 维修建议 Tab（折叠式）
- 卡片默认全部收起
- 收起态：仅显示主标题（如「前刹车片更换」「蓄电池检测」「空调滤芯更换」）、来源、状态标签和勾选框

- 点击展开后显示：情况说明 / 项目名称 / 建议项目 / 建议材料 / 预估工时/费用
- 按钮文案切换为 `收起`（带 ChevronUp 图标），可再次折叠
- 多张卡片的展开状态相互独立

### ✅ 11. 底部按钮按 Tab 切换
- `关联预约单` Tab：`关闭` + `关联选中预约单`
