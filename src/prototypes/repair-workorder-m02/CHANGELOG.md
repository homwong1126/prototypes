# 维修工单管理 - 更新日志

## 2026-05-26

### 🎯 整合弹窗 Tab 化

将创建工单页顶部的 `关联预约单 / 车辆权益 / 服务活动 / 维修建议` 弹窗合并为同一个整合弹窗，通过 Tab 切换四个区域：

- **Tab 顺序**：关联预约单 → 车辆权益 → 服务活动 / 品质改善 → 维修建议
- **Tab 数字徽标**：右侧展示待处理条数；数量为 0 时不显示
  - 关联预约单：候选预约单总数
  - 车辆权益：无徽标
  - 服务活动 / 品质改善：待处理服务活动数 + 待处理品质改善数
  - 维修建议：待处理维修建议数
- **底部按钮按 Tab 切换**：
  - `关联预约单`：关闭 + 关联选中预约单
  - `车辆权益`：仅关闭
  - `服务活动 / 品质改善`、`维修建议`：关闭 + 确认（仅写入当前 Tab 已勾选项）
- 顶部 4 个入口按钮全部进入同一弹窗并定位到对应 Tab，原独立的「关联预约单」弹窗 JSX 已删除
- 顶部按钮文案同步：`服务活动` → `服务活动 / 品质改善`；`关联预约单` 也带待处理数字徽标

### 🎯 新增「品质改善」业务能力

- **品质改善 = 召回（Recall）+ 技术升级（Technical Upgrade）**，与服务活动归并到同一 Tab
- 在 `服务活动 / 品质改善` Tab 内并行展示两个独立小节，各自带全选 checkbox、待处理徽标和数据表格
- 品质改善表格字段：活动名称、分类（召回 / 技术升级）、命中范围、优惠内容、关联项目、状态
- 召回项使用 `tag-fail` 红色 tag 突出风险；技术升级项沿用 `tag-pending` 蓝色
- 勾选确认后写入项目明细，维修类型固定为 `品质改善`，工种取 `品质改善` 对应的首个工种

### 🎯 维修建议折叠式卡片

- 维修建议 Tab 内每条卡片默认收起，仅展示主标题（如「前刹车片更换」「空调滤芯更换」）、来源、状态与勾选框
- 右侧新增 `展开 / 收起` 按钮（含 ChevronDown / ChevronUp 图标），点击后展开「情况说明 / 建议项目 / 建议材料 / 预估工时/费用」
- 折叠状态下卡片高度更紧凑，便于服务顾问浏览多条建议

### 🛠 代码层调整

- 删除 `vehicleInsightsMode` state，统一用 `vehicleInsightsTab`
- `openVehicleInsightsModal(tab)` 改为接受 Tab 参数，默认 `appointment`
- 删除 `showAppointmentModal` state 与独立 JSX
- 扩展 `handleConfirmVehicleInsights`：在 `campaign` Tab 时同时处理服务活动与品质改善
- 新增 `toggleRepairSuggestionExpanded(id)` 控制维修建议展开/收起
- 维修类型枚举沿用既有 `品质改善`，工种映射 `品质改善: ['机电', '软件升级']` 已存在

### 🎯 车辆查询 / 项目配件标签 / 收费类型显示

- **车辆查询 Tab 合并**：原 `本店车辆查询 / 车辆精确查询 / 它牌车查询` 三个 Tab 简化为 `车辆查询 / 车辆精确查询` 两个；本店车辆与它牌车合并到「车辆查询」Tab，结果按 `车辆状态 / 车辆用途` 区分；`lookupMode` 类型由 `'store' | 'precise' | 'other'` 改为 `'store' | 'precise'`
- **项目/配件标签颜色区分**：
  - 项目行标签：蓝色（`#176bf8` / `#e6f4ff`）
  - 配件行标签：橙色（`#fa8c16` / `#fff7e6`）
  - 用 inline style 强制覆盖，避免与 `.tag-pending`/`.tag-warning` 在全局样式中的同色覆盖冲突
- **收费类型显示规则**：
  - 单类型时按钮内显示原文（如 `客户自费 / 索赔 / 保险 / 内结`）
  - 多类型时按钮内直接显示完整分担：`保险50%｜自费30%｜索赔20%`，分隔符使用全角竖线 `｜`
  - 移除原「主收费类型 +N」缩略与副行 `charge-trigger-sub`，避免信息重复
  - 项目、配件、其他费用三处显示规则统一

委托书详情页面的时间轴已完整显示各个节点的完成时间：

- **待确认**：显示 `createdAt`（创建时间）
- **待派工**：显示 `confirmedStartAt`（确认开工时间）或 `createdAt`
- **待完工**：显示 `completedAt`（完工时间）✨
- **待质检**：显示 `completedReviewAt`（完工审核时间）
- **待交车**：显示 `deliveryAt`（交车时间）
- **已交车**：显示 `deliveryAt`（交车时间）

时间格式：`YYYY/MM/DD HH:mm`

#### 5. 业务逻辑实现

**完工操作** (`handleCompleteWork`)：
- 将工单状态从 `working` 更新为 `qc_wait`
- 记录完工时间 `completedAt`
- 更新 `updatedAt`

**质检操作** (`handleQcPass`)：
- 将工单状态从 `qc_wait` 更新为 `delivery`
- 记录质检时间 `completedReviewAt`
- 自动填充质检人 `completedReviewer`（如果未设置）
- 更新 `updatedAt`

**结算操作** (`handleSettle`)：
- 记录结算时间 `settlementAt`
- 工单状态保持为 `delivery`
- 更新 `updatedAt`
